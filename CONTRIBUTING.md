# Contributing to Stack Underflow

Thanks for your interest in Stack Underflow, an open source Q&A forum where university students can ask questions, tag them and help each other.

## Maintainers

Stack Underflow is maintained by our student team:

- Boris Dubovoy
- Adil Yergazy

The maintainers review pull requests, manage issues and make the final decision on what gets merged.

## Before you start

- Read our [Code of Conduct](CODE_OF_CONDUCT.md). By taking part, you agree to follow it.
- Read the [README](README.md) to set up the project locally (PostgreSQL, Django and Angular).
- Contributions submitted to this repository are intended to be distributed under the project's [MIT License](LICENSE). Only submit work you have the right to contribute.

## How to contribute

1. **Find or open an issue.** Check existing issues first. For a bug or feature request, open an issue describing it.
2. **Ask to work on it.** Comment on the issue so maintainers can coordinate work.
3. **Create a branch** from `main` with a short name, for example `fix-search-tags`.
4. **Make your change.** Keep each pull request focused on one issue.
5. **Run the checks** described in the README's "Verify the MVP" section (backend pytest suite and `npm run build` for the frontend). Mention any failing or unavailable checks honestly.
6. **Open a pull request** into `main`. Explain what changed and why; write `Closes #<issue number>` if applicable.
7. **Review.** A maintainer will review the PR and may request changes.

## Reporting bugs

Open an issue with steps to reproduce the bug, what you expected to happen and what actually happened. Do not post passwords, `.env` files or other secrets in issues.

## Reporting security or privacy problems

Please do not open a public issue for sensitive security problems. Contact a maintainer privately instead. See [PRIVACY.md](PRIVACY.md) for information about project data.
